# NetworkProxy

本项目包含一系列用于网络代理工具（如 Loon 等）的脚本，主要用于解锁部分 App 的会员功能。

## 支持的 App 及功能

| App        | App 安装                                                                                                       | 功能                         | 支持的 App 版本                           | 插件地址                                                                                                      |
| :--------- | :------------------------------------------------------------------------------------------------------------- | :--------------------------- | :---------------------------------------- | :------------------------------------------------------------------------------------------------------------ |
| Foodie     | [安装应用](https://apps.apple.com/cn/app/id1336411132)                                                         | 会员解锁                     | ≤ 7.4.40                                  | [安装插件](https://raw.githubusercontent.com/pixmason/NetworkProxy/main/Apps/Loon/Plugins/Foodie.plugin)      |
| 美图秀秀   | [安装应用](https://apps.apple.com/cn/app/id416048305)                                                          | 会员解锁                     | ≤ 12.9.0                                  | [安装插件](https://raw.githubusercontent.com/pixmason/NetworkProxy/main/Apps/Loon/Plugins/MeiTuXiuXiu.plugin) |
| 美颜相机   | [安装应用](https://apps.apple.com/cn/app/id592331499)                                                          | 会员解锁                     | ≤ 11.4.00                                 | [安装插件](https://raw.githubusercontent.com/pixmason/NetworkProxy/main/Apps/Loon/Plugins/BeautyCam.plugin)   |
| 美图全家桶 | [美颜相机](https://apps.apple.com/cn/app/id592331499) \| [美图秀秀](https://apps.apple.com/cn/app/id416048305) | 美颜相机 & 美图秀秀 会员解锁 | 美颜相机 ≤ 11.4.00 <br> 美图秀秀 ≤ 12.9.0 | [安装插件](https://raw.githubusercontent.com/pixmason/NetworkProxy/main/Apps/Loon/Plugins/MeiTuFamily.plugin) |
